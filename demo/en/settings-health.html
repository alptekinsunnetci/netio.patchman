Health checks

Checks that run before and after updates and can be started by hand. A check that passed before an update and fails after it raises a notification.

General Server configuration Notification channels Health checks Security score weights

Agents report CPU, memory and disk usage on their own; no check is needed for that. The checks here are extra ones such as websites, ports and services: they run before and after updates and at the monitoring interval. Measurement interval and warning limits

Local command checks

For security, the dashboard cannot send command lines to servers. For a custom check, place the script in the server's health.d directory and enter only its file name here. On Linux the file and directory must be owned by root and not writable by group or others, or the agent refuses to run it. Exit code 0 means healthy.

/etc/netio-patchman/health.d/<ad>    (Linux: root:root, 0755)
C:\ProgramData\netio-patchman\health.d\<ad>.ps1 | .cmd | .exe    (Windows)
