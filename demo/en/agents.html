Agent installation

  1. Create an enrollment token with the form on the right. The token is shown only once.
  2. Choose the server's operating system and run the generated command on the server to be managed:
    Installation requires root. sudo is not needed in a root session; if sudo is not installed (common on CentOS, Debian and Alpine), leave the box unchecked. The Debian and Alpine commands use wget instead of curl. Run the Windows command in PowerShell or a command prompt opened as administrator.
  3. The agent registers with the server, sends its inventory and appears on the Server Inventory page within a few minutes.
Servers without internet access

Download the files from these addresses, copy them to the server and run the install script with the --binary option:

https://patchman.example.test/downloads/agent/netio-patchman-agent-linux-amd64
https://patchman.example.test/downloads/agent/netio-patchman-agent-linux-arm64
https://patchman.example.test/downloads/netio-patchman-agent.service
https://patchman.example.test/downloads/netio-patchman-agent.openrc
https://patchman.example.test/downloads/install-agent.sh
sh install-agent.sh --server-url https://patchman.example.test --token <ENROLLMENT-TOKEN> --binary ./netio-patchman-agent-linux-amd64

Windows: copy the files to one folder and run this in PowerShell opened as administrator:

https://patchman.example.test/downloads/agent/netio-patchman-agent-windows-amd64.exe
https://patchman.example.test/downloads/install-agent.ps1
.\install-agent.ps1 -ServerUrl https://patchman.example.test -Token <ENROLLMENT-TOKEN> -Binary .\netio-patchman-agent-windows-amd64.exe
Supported systems

Inventory and updates: every distribution using apt (Debian, Ubuntu), dnf/yum (RHEL, AlmaLinux, Rocky Linux), zypper (SUSE, openSUSE) or apk (Alpine) with systemd or OpenRC (including CentOS, Oracle Linux and Fedora), and Windows 10, Windows 11 and Windows Server 2016 / 2019 / 2022 / 2025 (x64, Windows Update). Physical server, VMware, Hyper-V, KVM/Proxmox or cloud makes no difference. Vulnerability scanning: Debian, Ubuntu, AlmaLinux, Rocky Linux, Red Hat Enterprise Linux, CloudLinux 8/9 (with AlmaLinux data), SUSE Linux Enterprise, openSUSE Leap, Alpine and Windows (CVEs of pending Microsoft updates; third-party Windows programs are not scanned).
