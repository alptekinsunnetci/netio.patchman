Scheduled Updates

Update rules that run automatically on set days and times

New schedule

At the scheduled time, a job is created for every server in scope that has pending updates. If the agent does not connect within the maintenance window, the job does not run and is marked “Expired”; updates never slip into business hours. Unless this box is checked, netio.patchman does not restart servers; plan restarts separately so kernel updates take effect. When checked, a server that reports a pending restart after its update job finished is restarted one minute later, as long as the maintenance window is still open.
