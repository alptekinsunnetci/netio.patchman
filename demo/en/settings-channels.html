Add channel

In Slack, create an address for the channel with Apps → Incoming Webhooks (https://hooks.slack.com/services/…).

In the Teams channel, create an address with Workflows → "Post to a channel when a webhook request is received". Messages are sent as Adaptive Cards.

Each notification is POSTed as JSON (event, kind, level, title, text, url, params, created_at). HTTP is accepted; use HTTPS outside the internal network.

Create a bot with @BotFather and add it to the group. A group chat ID starts with a minus sign (-100…), or use a channel name (@channel_name).

Each notification opens an issue through REST API v2 (/rest/api/2/issue). Jira Cloud uses the account email and an API token, Jira Server a user name and personal access token.

Each notification is inserted through the Table API (/api/now/table/<table>, default incident). The user needs write access to that table.

The address is the GLPI REST API root (…/apirest.php). Enter the user's API token (user_token) as the token and the API client's App-Token as the application token. Each notification opens a ticket.

The notification is sent as JSON, as the value of a trapper item, with the Zabbix sender protocol. In Zabbix create a host with this host name and a text item of type "Zabbix trapper" with the same key; triggers can then use the value.

Events

With none selected every notification at or above the minimum level is sent. With events selected the level is ignored and only those events are sent.

Webhook addresses and bot tokens are secrets and are not shown in full after saving. To change one, delete the channel and add it again.
