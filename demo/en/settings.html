Email notifications

No SMTP server is configured. To send email, enter the SMTP server and sender address on the Server configuration page. Server configuration

Agents

Agents running a version other than the one the server distributes download the new version on their next connection, verify its SHA-256 digest and restart. At most 25 agents update at once; a failed update is retried after 6 hours.

Vulnerability scanning

Data sources: OSV.dev (distribution security advisories and CVE records), the Microsoft Security Update Guide (Windows), the CISA Known Exploited Vulnerabilities catalog and FIRST EPSS scores. The source addresses can be changed on the Server configuration page.

Security

When on, users without an authenticator can only open their profile page until they set one up.

Updates

Applies to servers whose agent supports previews (1.0.0+). Bulk actions, schedules and the API are not affected.

Resource monitoring

Agents report CPU, memory, swap and disk usage at the interval; the server page shows current values and 30 days of charts. Defined extra checks run at the same interval. A limit or check failing two measurements in a row is notified, and so is its recovery. Requires agent 1.0.2 or later.

These limits apply to every server without defining anything; 0 turns a limit off. For limits per server or group, add a CPU, memory and disk check on the Health checks page.

Remediation targets (SLA)

Days to resolve a finding after its first detection, by severity. 0 means no target for that severity. Overdue findings are marked and appear on the dashboard, in the report and in the notification center.

Software inventory

At most one notification per server report. The change history is always kept, regardless of this setting.

Automatic backup

Backups are written to the backup directory on the server; the newest backups are kept and older ones deleted. Since they only exist on this server, copy them elsewhere regularly too (PATCHMAN_BACKUP_DIR can point to a separate disk). If the server is down at the backup time, the backup runs when it starts.
