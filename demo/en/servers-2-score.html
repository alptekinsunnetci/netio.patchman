How is the score computed?

The score starts at 100 and the points below are deducted (minimum 0). On a server each CVE is penalized only once, with the highest criterion that applies; criteria are not added up. A pending security update does not count again if its package has an open finding. Software the distribution keeps maintaining does not count as unsupported.

  • Per CVE: critical 10, high 5, medium 2, low 0.5; CISA KEV 25; EPSS × 20; overdue 12 points. All vulnerabilities together deduct at most 70 points.
  • Unsupported operating system 25, support ending soon 5 points; each unsupported software release 5 points (at most 15).
  • Each pending security update without an open finding 1 points (at most 10).
