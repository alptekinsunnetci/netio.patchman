Assessment frameworks

  • Information security management audits isms@1
    Technical evidence asked for in information security management system audits: asset inventory, vulnerability management, change, logging, backup and access.
  • IT baseline protection audits baseline@1
    Module-oriented technical evidence for baseline protection assessments: patch and change management, Linux and Windows servers, Windows clients, logging and backup.
  • IT service management assessments itsm@1
    Evidence supporting IT service management practices: change enablement, release and deployment, configuration and asset management, monitoring and service levels.
  • General security & patch compliance general@1
    netio.patchman's own baseline security and update controls with measurable targets.
