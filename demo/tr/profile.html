API anahtarları

REST API (/api/v1/…) ve Prometheus (/metrics) için anahtarlar. Bir anahtar sizin rolünüz ve sunucu erişiminizle çalışır; salt okunur anahtarlar hiçbir şeyi değiştiremez. İstekte "Authorization: Bearer <anahtar>" başlığını gönderin. Ayrıntılar: docs/api.md.
