Bildirim kanalları

Bildirimleri Slack, Microsoft Teams, Telegram veya kendi sisteminize (webhook) de gönderin.

Genel Sunucu yapılandırması Bildirim kanalları Sağlık kontrolleri Güvenlik skoru ağırlıkları

Henüz bildirim kanalı yok.

Kanal ekle

Slack'te Apps → Incoming Webhooks ile kanal için bir adres oluşturun (https://hooks.slack.com/services/…).

Teams kanalında Workflows → "Post to a channel when a webhook request is received" şablonuyla bir adres oluşturun. Mesajlar Adaptive Card olarak gönderilir.

Her bildirim JSON olarak POST edilir (event, kind, level, title, text, url, params, created_at). HTTP de kabul edilir; iç ağ dışında HTTPS kullanın.

@BotFather ile bir bot oluşturun ve botu gruba ekleyin. Sohbet kimliği grup için eksi işaretiyle başlar (-100…) veya kanal adı olabilir (@kanal_adi).

Her bildirim için REST API v2 ile bir kayıt açılır (/rest/api/2/issue). Jira Cloud'da kullanıcı e-posta adresi ve API anahtarı, Jira Server'da kullanıcı adı ve kişisel erişim anahtarı kullanılır.

Her bildirim Table API ile bir kayıt olarak eklenir (/api/now/table/<tablo>, varsayılan incident). Kullanıcının bu tabloya yazma yetkisi olmalıdır.

Adres GLPI REST API kök adresidir (…/apirest.php). Anahtar alanına kullanıcının API anahtarı (user_token), uygulama anahtarına API istemcisinin App-Token değeri girilir. Her bildirim bir talep (Ticket) açar.

Bildirim, Zabbix sender protokolüyle bir trapper öğesinin değeri olarak JSON biçiminde gönderilir. Zabbix'te bu sunucu adıyla bir host ve aynı anahtarla "Zabbix trapper" türünde metin öğesi oluşturun; tetikleyicileri bu değere göre yazabilirsiniz.

Olaylar

Hiçbiri seçilmezse en düşük düzeyi geçen her bildirim gönderilir. Olay seçilirse düzeye bakılmaz, yalnızca seçilen olaylar gönderilir.

Webhook adresi ve bot anahtarı gizli bilgidir; kaydedildikten sonra tam olarak gösterilmez. Değiştirmek için kanalı silip yeniden ekleyin.
