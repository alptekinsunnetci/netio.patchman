Ajan kurulumu

  1. Sağdaki formdan bir kayıt anahtarı oluşturun. Anahtar yalnızca bir kez gösterilir.
  2. Sunucunun işletim sistemini seçin ve oluşan komutu yönetilecek sunucuda çalıştırın:
    Kurulum root yetkisi ister. root oturumunda sudo gerekmez; sudo kurulu değilse (CentOS, Debian ve Alpine'de sık görülür) kutuyu boş bırakın. Debian ve Alpine komutu curl yerine wget kullanır. Windows komutu yönetici olarak açılan PowerShell veya komut isteminde çalıştırılır.
  3. Ajan sunucuya kaydolur, envanteri gönderir ve birkaç dakika içinde Sunucu Envanteri sayfasında görünür.

Dosyaları bu adreslerden indirip sunucuya kopyalayın ve kurulum betiğini --binary seçeneğiyle çalıştırın:

https://patchman.example.test/downloads/agent/netio-patchman-agent-linux-amd64
https://patchman.example.test/downloads/agent/netio-patchman-agent-linux-arm64

Windows: dosyaları aynı klasöre kopyalayın ve yönetici olarak açılan PowerShell'de çalıştırın:

https://patchman.example.test/downloads/agent/netio-patchman-agent-windows-amd64.exe
https://patchman.example.test/downloads/install-agent.ps1
.\install-agent.ps1 -ServerUrl https://patchman.example.test -Token <KAYIT-ANAHTARI> -Binary .\netio-patchman-agent-windows-amd64.exe
Desteklenen sistemler

Envanter ve güncelleme: apt (Debian, Ubuntu), dnf/yum (RHEL, AlmaLinux, Rocky Linux), zypper (SUSE, openSUSE) ve apk (Alpine) kullanan, systemd veya OpenRC çalıştıran tüm dağıtımlar (CentOS, Oracle Linux ve Fedora dahil) ile Windows 10, Windows 11 ve Windows Server 2016 / 2019 / 2022 / 2025 (x64, Windows Update). Fiziksel sunucu, VMware, Hyper-V, KVM/Proxmox veya bulut fark etmez. Güvenlik açığı taraması: Debian, Ubuntu, AlmaLinux, Rocky Linux, Red Hat Enterprise Linux, CloudLinux 8/9 (AlmaLinux verileriyle), SUSE Linux Enterprise, openSUSE Leap, Alpine ve Windows (bekleyen Microsoft güncellemelerinin CVE'leri; üçüncü taraf Windows programları taranmaz).
